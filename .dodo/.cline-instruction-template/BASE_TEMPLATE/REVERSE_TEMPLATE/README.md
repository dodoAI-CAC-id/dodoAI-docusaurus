## Usage / 使い方

### English
1. Copy the content of `reverse-starter-template-en.md`
2. Replace `{MODULE_NAME}` with your actual module name
3. Select appropriate module types
4. Follow the analysis workflow step by step

### 日本語
1. `reverse-starter-template-ja.md`の内容をコピー
2. `{MODULE_NAME}`を実際のモジュール名に置き換え
3. 適切なモジュールタイプを選択
4. 分析ワークフローに従って段階的に実行
