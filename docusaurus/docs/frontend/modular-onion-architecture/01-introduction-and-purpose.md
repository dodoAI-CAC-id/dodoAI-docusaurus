# 01. Introduction and Purpose

## Overview

This development standard (ADF: Agentic Dev Framework) establishes common rules for achieving consistent, maintainable, and scalable design in Flutter applications. It specifically addresses the following challenges in team development and medium to large-scale projects:

* Ensuring layer responsibility separation and reusability
* Independent development and testing by feature
* Unified guidelines for UI composition and state management
* Eliminating architectural understanding discrepancies among developers

## Target Audience

* Flutter application architects and tech leads
* Developers using Bloc and Modular
* Project managers seeking common design rule establishment

## Out of Scope

* Basic explanations of Flutter SDK or language specifications
* Detailed implementation methods for individual libraries like Firebase or Stripe
