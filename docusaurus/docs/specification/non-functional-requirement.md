# Non Function Requirement

非機能要件定義書（Non-Functional Requirements：NFR）
「まもあい（mamoAI）」システム

1. はじめに
本定義書は、「まもあい」システムの非機能要件を明確化し、品質、信頼性、運用性、および法令遵守等の観点からプロダクト開発・運用上満たすべき基準を記述します。本ドキュメントは、継続的なレビューと改訂によって最新性・適合性を保ちます。

2. 可用性（Availability）
2.1 稼働時間
- 目標：24時間365日（24/7）の運用
- SLA目標：99.95% 以上（年換算で最大4.38時間以内の停止）

3. 性能・スケーラビリティ（Performance and Scalability）
3.1 応答性能
- 画像処理：60fps相当の動画入力をAI経由で常時処理
- 通知同時発生：1拠点で5件/分まで保証

3.2 拡張性
- スタンドアロンでの拠点増・機器追加に対する段階的横展開

4. 保守性・運用性（Maintainability and Operability）
4.1 バックアップ運用
-

4.2 監視・障害通知
- 死活監視（AI・アプリ・ストレージ等）は5分間隔で自動監視

4.3 保守作業・更新
- ソフトウェアバージョンアップは年2回程度予定

4.4 ユーザー操作・リソース管理
- 主要オペレーションはWebアプリまたはモバイルアプリより5分以内で完結できる操作性
- 権限管理およびユーザー追加・削除は管理者がGUIから操作可能

5. 移行性・拡張性（Portability and Migration）
- サーバ/ストレージの増設、現地レイアウト変更等にも柔軟に対応可能な構成

6. セキュリティ・プライバシー保護（Security and Privacy）
6.1 法令・規制対応
- 個人情報保護法等の国内法、医療・介護領域のガイドライン遵守（GDPR非該当地域だが意識は保持）
- 不要な個人情報の保持禁止、履歴動画・画像は不可逆なモザイク加工を実施

6.3 データ暗号化
- 通信時: 全通信をTLS1.2以上（HTTPSまたはgRPC+TLS）

6.4 監査・ログ
- 主要操作・アクセス・障害発生の監査ログを保存、管理者が随時参照可

7. システム環境・設置要件（System Environment and Ecology）
7.1 設置環境
- 商用電源（AC100V, 200V）、安定供給必須

8. サポート体制（Support & Maintenance）
- 導入時・運用開始時に現場オペレータ向けハンズオン研修・定着化支援提供

9. その他
- ドキュメント（ユーザー・運用管理者向け）は日本語、API仕様書は日本語/英語併記
- 内部統制、PL保険加入

付録：要件トレーサビリティ
経営層、現場スタッフ、医療チーム、R&D部門、開発ベンダーまで対象とし、マイルストン毎のNFR見直しを実施
