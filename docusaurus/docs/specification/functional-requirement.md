# Functional Requirement

| ID    | Requirement Area       | Functionality                         | Description / Key Points                                                                                                                                         | Outcome / Objective                         |
|-------|-----------------------|---------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------|
| FR-01 | AI画像検知            | 異常姿勢検知（転倒・離床等）            | ベッド周辺カメラ映像をAI（物体検知＋姿勢推定）で監視。転倒/離床等をリアルタイム判別しイベントとして即時通知。誤検知・漏検は一定水準で抑制。       | 異常発生を即座に認識・人的遅れを解消し安全性向上 |
| FR-02 | 異常通知              | 異常発生通知トリガ                    | AI検知イベント発生時に異常発生通知生成（3秒以内）。異常レベル分類（緊急・注意・軽微）、優先度設定、通知エスカレーション機能あり。                | スタッフへ迅速な注意喚起＋優先度対応         |
| FR-03 | 異常通知              | モザイク画像付き通知生成               | プライバシー配慮の自動モザイク画像/動画サムネイル付与。AI判定と同フローで実行。                                           | 個人情報リスク回避・現場要求両立             |
| FR-04 | 異常通知              | 通知送信（端末配信/PUSH）、通知制御     | 全端末（PC・モバイル等）へ即時配信。部署/担当者別通知ルーティング。時間帯別通知先切替。既読/未読状態管理と未読アラート再送も含む。             | 全スタッフが同時に状況把握、伝達漏れ防止     |
| FR-05 | 異常通知履歴          | 履歴記録（異常イベント・画像）         | 異常発生詳細・関連情報を即時DB保存。改ざん防止。通知既読/未読状態・エスカレーション履歴もログ化。                          | 事後検証や証跡確保に活用                     |
| FR-06 | 履歴動画管理           | 履歴動画自動記録                      | 異常発生直前後最大5分間の映像を自動保存。モザイク処理必須。                                                                | 事後確認・証跡、ストレージ効率運用           |
| FR-07 | 履歴動画管理           | 履歴動画検索/再生/高度検索             | 対象者・日付・種別等で動画/履歴検索、複数条件・ソート、検索条件保存・再利用可。複合検索の実現。選択した履歴動画（モザイク処理済）を端末上で再生可能。 | 必要な動画を迅速特定・業務効率化             |
| FR-10 | 対応アクション登録     | 訪室対応スタッフ登録・対応履歴          | 通知受信後、現場対応者が「対応中」を登録、誰がいつ対応中か履歴化。重複防止・リアルタイム共有も行う。                         | 役割分担最適化・対応漏れ排除                 |
| FR-11 | 対応アクション登録     | 対応完了／監視再開登録                  | 対応完了時に明示登録し再監視へ自動切替。再発時には改めて通知トリガとなる。                                                | 一連対応フロー明確化・運用手順遵守           |
| FR-12 | 履歴管理               | 履歴情報一覧/詳細参照・高度フィルタ      | 異常/対応/スタッフ/履歴種別等一覧・詳細参照。指定条件で柔軟なフィルタリング。                                            | 状況把握・申し送り・監査利用                 |
| FR-16 | 対象者情報管理         | 対象者リスト登録/編集/履歴紐付           | 監視対象者（ID/部屋番号/注意事項等）の登録・編集・削除。履歴情報への紐付け管理。                                         | 対象者特定・すべての履歴連携                 |
| FR-18 | システム監査           | イベント/操作ログ記録・監査              | 異常検知・通知・アクション・設定変更等、各種操作のイベント/監査ログ記録。誰がどのデータを閲覧/操作したか監査可能。         | 事故/トラブル追跡・監査報告対応              |
| FR-20 | カメラ・デバイス管理    | カメラ登録・削除・設定／監視エリア紐付   | 物理カメラ/デバイスを登録・削除。監視エリア（部屋）紐付け、個別の検知エリア設定にも対応。                               | 設備増減や現場配置変更に柔軟対応              |
| FR-22 | システム設定管理       | AI設定/感度・動画保存・通知タイムアウト設定| 管理者によるAI検知感度、動画保存期間、通知タイムアウト等の詳細パラメータ設定が可能。                                     | 保存/運用要件への柔軟な適合                  |
| FR-26 | 検知設定               | カメラ毎監視ON/OFF管理／履歴紐付          | 各カメラや部屋ごとにAI監視ON/OFF、稼働/停止履歴も自動記録で運用柔軟化。                                                | 運用都合適用・不要誤通知の予防               |
| FR-27 | 通知配信制御           | 通知先ルーティング・時間帯別設定           | 時間帯に応じて通知の配信方法を細かく設定・運用。設定情報にも変更履歴を記録。                                            | 通知伝達ロス排除・業務要件適合                |
| FR-29 | 対応状況可視化         | 全現場対応案件ダッシュボード               | 異常対応中のスタッフと案件進捗（未対応/進行/完了）を全員で可視化し、現場状況を一目で把握可能。                          | リソース最適化・対応抜けの即時認知            |
