# システム環境とエコロジー – 定義ガイド

- このガイドを使用して、システムの環境とエコロジー要件を包括的に定義します。
- サンプル文言をそのままコピーしないでください。常に実際のシステムアーキテクチャ、ビジネス特性、運用環境に各項目を適応させてください。
- 各項目について、何が必要か、根拠、関連するレベルまたはポリシー、メトリクスや条件を明確に指定してください。

## 1. システム制約と前提

### 1.1 構築時制約
- **定義すべき内容:** システム構築に影響する内部ポリシー、法律、または必須標準、場所固有または政府規制を含む
- **例:** SOX、ISO27000シリーズ、国家セキュリティ標準、プライバシーマーク、サイト制限
- **レベル:** 制約なし / 重要な制約のみ適用 / すべての関連制約適用

### 1.2 運用制約
- **定義すべき内容:** 運用中に従わなければならない適用標準/法律または条例/組織規則
- **例:** データプライバシー、J-SOX、リモート運用に関する規制
- **レベル:** 制約なし / 重要な制約のみ / すべての制約

## 2. システム特性

### 2.1 ユーザーとクライアント規模
- **ユーザー数:** 特定のユーザーのみ、上限のある数、または無制限/未特定の数のユーザーがシステムを使用するかを定義
- **クライアント数:** 上記と同様、ただしクライアントシステム/デバイスについて
- **サイト数:** システムが1つの場所で稼働するか複数の場所で稼働するかを示す
- **地理的広がり:** 展開エリアを明確化（単一サイト、市、地域、国、グローバル）

### 2.2 製品/コンポーネント仕様
- **特定製品:** 指定されたOSS/サードパーティ製品を使用する必要があるかを記載し、サポート性への影響を考慮
- **システム使用範囲:** 使用が部門内、会社全体、またはB2B/B2C外部使用を含むかどうか
- **多言語サポート:** 複数言語が必要かどうか（何言語）；必要に応じて言語アクセシビリティを考慮

## 3. コンプライアンスと標準

### 3.1 製品安全標準
- **定義すべき内容:** システムが認定されたハードウェア/製品のみを使用する必要があるかどうか（例：UL60950）
- **レベル:** 不要 / 標準に準拠（UL60950、RoHS、VCCI クラスA/B等）

### 3.2 環境保護
- **定義すべき内容:** 製品がRoHS（有害物質制限）または類似標準に準拠する必要があるかどうか

### 3.3 電磁干渉
- **定義すべき内容:** EMI/EMC標準への準拠が必要かどうかを記載

## 4. 機器/フロア設置要件

### 4.1 耐震・耐振動性
- **定義すべき内容:** 場所による最大耐震性要件
- **レベル:** 要件なし、東海/東北地震（例：マグニチュード4、5、6、または7）、ガル（加速度）で設定

### 4.2 床面積と物理的制約
- **定義すべき内容:** 必要な空間（幅×奥行×高さ）、ラック/床の詳細、並行運用（移行中）の特別制約
- **サブ項目:**
  - マシンルーム空間/制限
  - オフィス設置（専用/共有空間）
  - 並行稼働または拡張のための空きスペース
- **考慮事項:** 拡張と並行移行の必要性とのバランス

### 4.3 重量と荷重
- **定義すべき内容:** 平方メートルあたりの重量制限と対策（補強、荷重分散、ラック使用）
- **レベル:** 例：200kg/m²から2000kg/m²以上、設置改修の要件

### 4.4 電気・冷却適合性
- **定義すべき内容:** 電源供給、電圧、相、回路の互換性、および空調/冷却要件
- **サブ項目:** 電力充足性、カスタム工事の必要性、並行稼働の容量、停電対策、電圧・周波数変動許容度、接地タイプ

### 4.5 温度・湿度範囲
- **定義すべき内容:** 安定した運用に必要な動作温度と湿度帯域
- **レベル:** 標準範囲（例：16-32°C、5-35°C、0-40°C）から特別条件の拡張範囲まで。湿度は「制限なし」から45-55%、より広いレベルでの結露なしまで

### 4.6 空調・冷却能力
- **定義すべき内容:** すべての機器に対して冷却が適切か、ホットスポットがあるか、アップグレードが必要か
- **レベル:** 制約なし、部分的制約（容易に処理可能）、深刻な制約（カスタムエンジニアリングが必要）

## 5. 環境管理

### 5.1 環境配慮とグリーン調達
- **定義すべき内容:** 環境配慮製品（例：日本のグリーン購入法）をどの程度使用するか、システム拡張/廃棄が環境負荷にどう影響するか
- **レベル:** 不要、部分的にグリーン準拠、完全にグリーン準拠

### 5.2 拡張可能性とライフサイクル
- **定義すべき内容:** ハードウェア/構成拡張の能力（倍率で表現：2倍、4倍、10倍等）、およびライフサイクル期間（例：3年、5年、10年）

### 5.3 エネルギー消費効率
- **定義すべき内容:** 総エネルギー使用、電力効率、またはPUEやDPPEなどのエネルギーベンチマークの使用に対する目標またはポリシー
- **レベル:** なし、目標あり、目標と改善メカニズムあり

### 5.4 CO2排出管理
- **定義すべき内容:** 製品/システムライフサイクルにわたってCO2最大しきい値があるかどうか；継続的削減の目標または要件があるか

### 5.5 騒音/振動
- **定義すべき内容:** 騒音放出レベル要件（例：オフィス用87dB未満；静かな環境用40dB以下）

---

## ドキュメントポイント

- すべての項目について、正確な範囲と要件レベルを根拠とともに記載し、可能な場合は測定標準やメトリクスを含める
- 重要な制約とそのビジネス/技術的影響を記載
- 環境、コンプライアンス、ビジネス拡張計画と要件を整合させる

---

**目的**

これらのガイドラインは、システムの環境およびコンプライアンス要件が明示的で現実的であることを確実にし、プロジェクトリスクを最小化し、システムライフサイクル全体を通じて拡張、グリーン管理、安全運用のサポートを可能にします。
