## インストラクション
以下のフォーマットに従って、Markdownでユーザーストーリーリストを作成してください。


## 概要
ユーザーストーリーリストは、現代のソフトウェア開発において重要です。これらはユーザーの視点から要求を詳細に記述し、いくつかの重要な目標を達成するために役立ちます。


#### 目標：
1. **明確さ**：ユーザーの要求を明確に表現する。
2. **優先順位付け**：機能の重要度によってランク付けする。
3. **整合性**：チームが理解を共有する。
4. **漸進的開発**：ステップバイステップの進行を促進する。
5. **ユーザー中心のフォーカス**：実際のユーザー価値を提供する。
6. **柔軟性**：変更やフィードバックに適応する。

#### なぜユーザーストーリーリストが必要か？
1. **要求の伝達**：ユーザーのニーズを明確にキャプチャし伝える。
2. **作業の優先順位付け**：高価値な機能に焦点を当てる。
3. **整合性の確保**：チームを同じ方向に導く。
4. **アジャイル開発の支援**：反復的・漸進的な進行を可能にする。
5. **変更への適応**：新しい情報に迅速に調整する。
6. **ユーザー満足度の向上**：ユーザーの期待に応える製品を作る。

## dodoAIを使用したユーザーストーリーリスト作成の方法

このタスクを処理するためにSSツールに機能を作成しました。前に提供した機能要件（サービス要件）を入力して完了します。以下に使用方法と必要な情報を示します。

ユーザーストーリーリストは、SSツール（Design → User Story Lists）からさまざまな入力に基づいて生成されます。

<!-- ![User Story Lists](assets/user-story-lists.png) -->

- サンプルプロンプト: [User Story Lists](https://58llm.link/main/restore/30367bc6-06a3-4b95-9c1e-37f7e583f7c2)

### 入力内容

- 指示
- 機能要件（サービス要件）

### 指示


```
要求: あなたは多くの経験を持つビジネスアナリスト（BA）であり、あなたのビジネスアナリスト（BA）職に関連する任意のタスクを処理できます。私が以前提供した機能要件（サービス要件）に基づいてユーザーストーリーリストを作成してください。

以下に従うべきタイトルを提供しました。以下のテンプレートに従ってユーザーストーリーリストを作成してください。このテンプレートに従うことで、結果が正確で提供されたテンプレートに密接に従うことができます。


分類 | # | ユーザーストーリー名 | アクター | アクション | 目的
```

### 機能要件（サービス要件）（サンプル）
```
以下のサービス要件に基づいてユーザーストーリーを取得してください。

機能要件（サービス要件）:

# 認証とユーザーアカウント
## Firebase認証
- Firebase認証を認証として使用
- メール/パスワード
- Googleログイン
## 多言語サポート
- 以下の言語に切り替え可能
  - 英語
  - 日本語
  - ベトナム語

```

## 出力
```
以下は提供された機能要件（サービス要件）に基づくユーザーストーリーリストです。構造は指定されたテンプレートに従っています:

### 分類: 認証とユーザーアカウント

| #  | ユーザーストーリー名               | アクター  | アクション                                 | 目的                                                                            |
|----|-----------------------------------|----------|--------------------------------------------|--------------------------------------------------------------------------------|
| 1  | メールによるユーザー登録          | ユーザー  | メールを使用して新しいアカウントを登録     | ユーザーがメールとパスワードを提供してアカウントを作成できるようにするため   |
| 2  | メールによるログイン              | ユーザー  | メールとパスワードでログイン               | ユーザーが登録したメールで安全にアカウントにアクセスできるようにするため     |
| 3  | Googleによるログイン              | ユーザー  | Googleアカウントでログイン                 | ユーザーが代替の便利な方法でログインできるようにするため                     |

### 分類: 多言語サポート

| #  | ユーザーストーリー名               | アクター  | アクション                                 | 目的                                                                            |
|----|-----------------------------------|----------|--------------------------------------------|--------------------------------------------------------------------------------|
| 4  | 英語に言語を切り替え               | ユーザー  | 英語を選択して優先言語に設定               | ユーザーが英語でアプリケーションを使用できるようにするため                   |
| 5  | 日本語に言語を切り替え             | ユーザー  | 日本語を選択して優先言語に設定             | ユーザーが将来的に日本語でアプリケーションを使用できるようにするため         |
| 6  | ベトナム語に言語を切り替え         | ユーザー  | ベトナム語を選択して優先言語に設定         | ユーザーが将来的にベトナム語でアプリケーションを使用できるようにするため     |

注: 「日本語」および「ベトナム語」の言語オプションについては、これらのユーザーストーリーはバックログアイテムとしてマークされており、今後の実装が予定されています。
```
