## 概要
ワイヤーフレームは、アプリケーションのユーザーインターフェースの骨組みを確立するもので、構造とユーザー体験を優先してプロジェクトのデザインと開発に役立つ情報を提供します。

## 目標
ワイヤーフレーム作成の目的は以下の通りです：

- ユーザーインターフェースレイアウトの基本的な構造を作成すること。
- 初期段階からステークホルダーからのフィードバックを得ることを促進すること。
- 使いやすさに関する問題を早期に発見して解決すること。
- プロジェクトチームの全メンバーが共通の方向性とビジョンを共有すること。

## 作成方法
ワイヤーフレーム作成には主に2つの方法があります：

1. **ゼロから作成：**
   完全なカスタマイズとオリジナルのデザインアイデアを可能にするため、[Uizardのステップバイステップガイド](https://uizard.io/blog/website-wireframing-a-step-by-step-guide/)を参照し、ゼロからワイヤーフレームを作成します。

2. **デザインシステムを使用：**
   プロジェクトにデザインシステムがある場合、予め定義されたコンポーネントやレイアウトを使用してワイヤーフレームを作成します。これにより、既存のデザイン基準と一貫性を持たせ、ワイヤーフレーム作成プロセスを加速できます。

## ワイヤーフレーム作成ツール
これからは、すべてのワイヤーフレームは **Figma** を使用して作成および管理されます。Figmaは、コラボレーションと効率的なワイヤーフレーム作成を可能にするプラットフォームであり、チーム全員が一貫性を持ってアクセスできます。

- **Figmaへのアクセス**: プロジェクトのFigmaワークスペースにアクセスできることを確認してください。アクセス権が必要な場合はプロジェクトマネージャーに連絡してください。
- **テンプレート**: Figmaで利用可能なテンプレートを使用するか、プラットフォーム内で新しいワイヤーフレームを直接作成してください。
