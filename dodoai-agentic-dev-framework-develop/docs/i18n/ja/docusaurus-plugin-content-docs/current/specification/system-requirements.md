## インストラクション
指定されたソフトウェアソリューションの運用、開発、デプロイメントに必要な高水準のシステム要件をMarkdown形式で作成してください。

## 概要
この文書は、指定されたソフトウェアソリューションの運用、開発、デプロイメントに必要な高水準のシステム要件を定義します。

## 目標
ソフトウェア、ミドルウェア、プログラミング言語、インフラストラクチャ、スケジューリング、テスト環境、およびシステムの機能とパフォーマンスを実現するために必要な追加コンポーネントの包括的な構造を定義することです。

**ご注意：以下の出力サンプルは参考用です。この形式をガイドとして使用し、特定のシステム要件に合わせて内容を調整してください。**

## 出力サンプル
```
# システム要件

## ソフトウェア／ミドルウェア
- **Scalar DB**: ScalarDB 3.14
- **Scalar DL**: ScalarDL 3.11

## プログラミング言語
- **Java**: OpenJDK 17

## インフラストラクチャ
- **リージョン**: AWS 東京リージョン (ap-northeast-1)
- **コンテナサービス**: Amazon ECS (Elastic Container Service)を使用
- **データベース**: Amazon DynamoDBを使用

## スケジューリング
- **Amazon EventBridge**: 定期的なイベントトリガーのためにcron式を使用
  - 例: `cron(0 12 * * ? *)` 毎日正午に実行

## パフォーマンステスト環境
- **Amazon EC2**: パフォーマンステストの実施に使用
  - テストツール: 確認中
  - インスタンスタイプ: 要件に応じた適切なタイプ (例: t3.medium, t3.large)

## その他
- **ロードバランサー**: アプリケーションロードバランシング
- **監視およびログ**: Amazon CloudWatch
- **ECS AutoScalingのしきい値**: 検討中
```
