## 指示
以下の形式に従って、機能要件をMarkdown形式で作成してください。

## 概要
機能要件は、ソフトウェアシステムが実行すべき操作を詳細に説明し、開発者やステークホルダーにユーザーの要求を満たすために必要な機能を伝えるものです。

## 目標:
1. システム機能の定義。
2. ユーザーの期待に応える。
3. 品質の確保。

## 機能要件の必要性
- 開発のニーズを明確にする。
- システムテストを可能にする。
- システム変更を管理する。


## 出力
このテンプレートをプロジェクトのサービス固有の要件に合わせて調整し、各機能がその操作と結果を定義するようにしてください。

```
# [サービス名] 機能要件

## 概要
[サービスの主な機能と他のサービスとの相互作用の説明。]

## 機能要件

### 1. [最初の機能カテゴリ]
#### 1.1 [最初の機能]
この機能が含む内容とその結果を説明します。
#### 1.2 [2番目の機能]
この機能がどのように動作し、その目的が何であるかを説明します。

### 2. [次の機能カテゴリ]
#### 2.1 [3番目の機能]
この機能が実行するアクションとその要件の詳細を説明します。
#### 2.2 [4番目の機能]
この機能のプロセスと求められる結果の概要を示します。

[サービス要件に基づいて、追加の機能を続けて記載してください。]
```
