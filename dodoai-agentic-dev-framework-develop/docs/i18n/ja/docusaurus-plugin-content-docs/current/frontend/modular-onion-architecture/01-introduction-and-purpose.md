# 01. 導入と目的

## 概要

この開発標準（ADF: Agentic Dev Framework）は、Flutterアプリケーションにおいて一貫性があり、保守可能で、スケーラブルな設計を実現するための共通ルールを確立します。特に、チーム開発や中〜大規模プロジェクトにおける以下の課題に対処します：

* レイヤー責任分離と再利用性の確保
* 機能別の独立した開発・テスト
* UI構成と状態管理の統一ガイドライン
* 開発者間のアーキテクチャ理解の相違解消

## 対象読者

* Flutterアプリケーションアーキテクトとテックリード
* BlocとModularを使用する開発者
* 共通設計ルール確立を求めるプロジェクトマネージャー

## 対象外

* Flutter SDKや言語仕様の基本説明
* FirebaseやStripeなど個別ライブラリの詳細実装方法
