## デイリーレポートとSlack利用ルール

## デイリーレポート

以下のリンクに勤務開始時間を投稿してください：

[Weekly Goals Set](https://www.notion.so/Weekly-Goals-Set-370224c75e9b4a70b2849b8f035fa560)

### デイリーレポートのフォーマット：

    ◆昨日の作業内容
    - `[Issueタイトル](リンク)` --> ステータス: "進行中（??%）" または "レビュー中" または "完了".

    ◆本日の作業予定
    - `[Issueタイトル](リンク)`

    ◆現在の課題・問題点
    - N/A または 問題内容

プロジェクトメンバーは毎日午前9:00（VNT GMT+7）までにレポートを提出してください。

## Slack利用ルール

- 業務関連のコミュニケーションでは、できるだけダイレクトメッセージの使用を控え、プロジェクトチャンネルを使用してください。他のメンバーも会話を参照できるようにするためです。
- 例外: やむを得ない場合、個人的または機密情報を扱う場合のみ、ダイレクトメッセージを使用してください。
