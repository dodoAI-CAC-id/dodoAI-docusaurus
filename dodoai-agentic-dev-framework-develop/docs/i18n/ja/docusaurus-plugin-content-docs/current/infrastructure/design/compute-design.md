# ガイド: コンピュートインフラストラクチャ設計の定義

- このガイドを使用して、マイクロサービス/クラウドネイティブ環境でのコンピュートインフラストラクチャのすべての要件、選択、パラメータ化を明示的に定義してください。
- 実装サンプルや説明は含めず、サービス、階層、またはクラスターごとに指定すべき内容をリストアップしてください。

---

## 定義すべき内容

### 1. コンピュートリソース戦略

- **インスタンス/ノードタイプ:**  
  - 各ワークロード階層（web、アプリケーション、データベース、ワーカーなど）のインスタンスファミリーとタイプ選択、最小/最大/希望サイジング、vCPU/メモリ/ネットワーク要件を文書化してください。
  - どの環境/階層がオンデマンド、リザーブド、またはスポット/プリエンプティブルインスタンスを使用するかを指定してください。
  - リソース分散のためのAZ（アベイラビリティゾーン）とリージョン戦略。

### 2. コンテナオーケストレーションとクラスター設計

- **クラスター管理:**  
  - プラットフォーム（EKS、ECS、AKS、GKEなど）とバージョニング要件を指定してください。
  - ノードグループ/プール設定—ラベル、容量タイプ、最小/最大サイズ、インスタンスタイプ。
- **ポッドとワークロードリソース設定:**  
  - 名前空間レベルのリソースクォータと個別のポッド/コンテナリソースリクエスト、制限、セキュリティコンテキストを定義してください。
  - 特権ポッド、rootと非root、ユーザー/グループ割り当てのポリシーを指定してください。

### 3. 自動スケーリングとパフォーマンス

- **水平スケーリング:**  
  - HPA/VPA設定：メトリクスしきい値、最小/最大レプリカ、ワークロードごとのスケーリングポリシー。
- **クラスターオートスケーラー:**  
  - クラスタースケーリングパラメータ、ダウンスケール遅延、最大ノードプロビジョニング時間を定義してください。
- **CPUとメモリ管理:**  
  - 監視しきい値、JVM/コンテナメモリフラグ、スワップ/オーバーコミット、パフォーマンスポリシー。

### 4. サーバーレスコンポーネント

- **関数デプロイメント:**  
  - 使用中のすべてのサーバーレスコンピュート（Lambda/ECS Fargate/Cloud Functionsなど）、ランタイム、メモリ/タイムアウト設定、ハンドラー設定をリストアップしてください。
- **コンテナ化バッチ/プロセス:**  
  - スケジュール/バックグラウンドサービスのタスク定義、ネットワーキング、リソース配分。

### 5. ロードバランシングと高可用性

- **LB技術と設定:**  
  - LBタイプ（ALB、NLB、内部/外部）、ヘルスチェックパス、プロトコル、バランシング/アルゴリズム、クロスAZ設定を指定してください。
- **高可用性:**  
  - すべての層（web、app、DB）の明示的なAZ分散と各層の最小必要インスタンス/ノード数。

### 6. 監視とアラート

- **メトリクス:**  
  - アプリケーションレベルとインフラストラクチャレベル（レイテンシ、エラー率、CPU、メモリ、ネットワークなど）の両方で収集すべき必要なメトリクス名前空間とメトリクス。
- **アラートポリシー:**  
  - すべての重要なリソース使用率とエラーのしきい値、アラートチャネル、エスカレーションポリシーを定義してください。
