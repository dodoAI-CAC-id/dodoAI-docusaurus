## Terraformコード
Terraformを取得するには、以下の手順に従ってください。

```
git clone git@github.com:58web3/llm.git
cd llm/infra
```

## Terraformファイル説明

以下は、各ファイルの内容と目的に関するディレクトリリストと説明です。

```
├── be.tf
├── ecs-cluster.tf
├── fe.tf
├── locals.tf
├── main.tf
├── output.tf
├── service-roles.tf
├── variables.tf
└── vpc-alb.tf
```

### ファイルの説明

#### 1. `be.tf`
**目的:**
'be' は通常「バックエンド」の略です。
**内容:**
- バックエンドサーバーの仕様、設定、サービスを定義します。

#### 2. `ecs-cluster.tf`
**目的:**
このファイルは、AWS ECS（Elastic Container Service）クラスターに固有の設定を定義および管理します。
**内容:**
- ECSクラスターの作成および設定。
- ECSタスク定義やサービスとの統合の可能性。

#### 3. `fe.tf`
**目的:**
'fe' は通常「フロントエンド」の略です。
**内容:**
- フロントエンドサーバーの仕様、設定、サービスを定義します。

#### 4. `locals.tf`
**目的:**
プロジェクト内でリソース定義やデータの検索を簡素化するローカル値を含みます。
**内容:**
- 複数のリソースやモジュールで再利用されるローカル値。
- 一般的なタグ、名前、設定などの再利用可能な値を定義するのに役立ちます。

#### 5. `main.tf`
**目的:**
Terraform実行計画のエントリーポイント。通常、インフラストラクチャ全体のセットアップを調整します。
**内容:**
- プロバイダ設定を宣言するための主要な設定を含みます。

#### 6. `output.tf`
**目的:**
Terraform状態の出力を定義します。
**内容:**
- ALBやECSに関連する特定の情報を出力するための出力ブロックを含みます。

#### 7. `service-roles.tf`
**目的:**
インフラストラクチャ内のさまざまなサービスに対するロールと権限を定義します。
**内容:**
- ECSサービス用のIAMロールおよびポリシー。

#### 8. `variables.tf`
**目的:**
このファイルは、入力変数を宣言および定義するために使用されます。
**内容:**
- 型制約、デフォルト値、および説明を含む変数定義。

#### 9. `vpc-alb.tf`
**目的:**
仮想プライベートクラウド（VPC）およびアプリケーションロードバランサー（ALB）のコンポーネントを定義します。
**内容:**
- VPC、サブネット、ルートテーブル、およびネットワーキングに必要な設定および管理。
- ALBの定義、ターゲットグループ、リスナー、およびリスナールールを含みます。
- ネットワーキングおよびロードバランシングに特化したセキュリティグループ設定。
