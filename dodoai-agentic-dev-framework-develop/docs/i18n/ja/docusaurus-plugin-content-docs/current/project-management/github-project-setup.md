## 概要

GitHub プロジェクトのセットアップを開始する前に、GitHub と Notion のセットアップが完了していることを確認してください。これらの事前準備は、スムーズな統合とワークフローのために重要です。

- [GitHub セットアップ](github-setup)
- [Notion セットアップ](notion-setup)

GitHub と Notion の初期セットアップが完了したら、GitHub プロジェクトの設定に進みます。 このセットアップの目的は、プロジェクトの進捗を管理しやすい、直感的で使いやすい環境を作ることです。 開発者が作業の進捗を簡単に更新できるようになり、効率的なインターフェースによって多彩な管理オプションが提供されます。GitHub に統合されたツールにより、プロジェクトのロードマップや進行状況の追跡が簡単になり、チームの開発プロセスの効率向上をサポートします。

## 基本情報

- プロジェクトのプライバシー設定を構成する。
- GitHub プロジェクトを関連するリポジトリにリンクする。
- 1 つのリポジトリには、複数の GitHub プロジェクトを作成可能。それぞれ異なる目的を持たせることができる。

## GitHub プロジェクトのセットアップ方法

### **ステップ 1: プロジェクトの初期化**

- リポジトリの「Projects」セクションに移動し、「New Project」をクリック。

  <!-- ![プロジェクトへのアクセス](assets/github-project-setup/github-project.png) -->

### **ステップ 2: プロジェクト設定の構成**

- プロジェクトの構成をカスタマイズ:
  - 標準テンプレートまたは組織が提供するテンプレートのどちらかを選択。

    <!-- ![新規プロジェクト作成](assets/github-project-setup/create-new-project.png) -->
  - 組織のテンプレートを使用する場合は、適切なプロジェクト名を設定し、「Create Project」を選択。 GitHub のデフォルトテンプレートを使用する場合も、同様の手順で名前を設定。
<!-- ![プロジェクト名の設定](assets/github-project-setup/set-project-name.png) -->
  - 既存のテンプレートを使用しない場合は、テンプレート選択ウィンドウを閉じる。
<!-- ![テンプレート選択ウィンドウを閉じる](assets/github-project-setup/close-template-selection.png) -->

※ **注:** プロジェクト名はいつでも変更可能。

  <!-- ![プロジェクト名の変更](assets/github-project-setup/rename-project.png) -->

### **ステップ 3: Issue と開発フローの管理**

- Issue を整理し、タスクを割り当てるために、各 Issue をプロジェクトにリンク。

  <!-- ![Issue をプロジェクトにリンク](assets/github-project-setup/link-issue-to-project.png) -->

- リンクされた Issue はプロジェクトのダッシュボードで確認でき、進捗管理が容易に。

  <!-- ![プロジェクトビュー](assets/github-project-setup/project-view.png) -->

### **ステップ 4: マイルストーンの設定**

- GitHub マイルストーンを作成し、プロジェクトの明確なタイムラインを確立。 詳細な設定手順は、以下のガイドを参照: [GitHub マイルストーン](../project-management/github-milestone-setup.md)
