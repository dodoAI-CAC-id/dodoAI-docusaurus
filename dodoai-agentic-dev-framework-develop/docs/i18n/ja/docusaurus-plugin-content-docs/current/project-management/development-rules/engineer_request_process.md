## プロジェクトのためのエンジニア要求プロセス

プロジェクトの技術的および機能的要件、SDF、プロジェクトの役割と責任に基づいて、PMは以下のテンプレートに示される情報を使用してエンジニア要求を作成する必要があります。

要求情報は、テックリードチャンネルを通じてTriさん（@Tri (Le Cao Tri)）に送信し、Murakamiさん（@Jin/Hitoshi Murakami）をccにしてください。

[Slackのテックリードチャンネル](https://58-crew.slack.com/archives/C050P7YTAUU)
