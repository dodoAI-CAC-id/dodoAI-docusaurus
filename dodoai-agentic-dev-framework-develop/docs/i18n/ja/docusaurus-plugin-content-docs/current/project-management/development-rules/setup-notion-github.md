## Notion & Github 設定およびドキュメント管理

## GitHub プロジェクトの設定

GitHubでの登録が完了したら、GitHubプロジェクトを設定します。
ガントチャートを使用して、開発者が概要を簡単に確認できるようにします。
管理を容易にするために、イテレーション（スクラムユニット）を表示し、タスクをマイルストーンごとにグループ化します。

## プロジェクトドキュメントの設定（Docusaurus）

58では、AIエージェントが設計を正しく理解することに基づいて作業を行います。そのため、要件定義から設計までのドキュメントを機械可読形式で管理することが重要です。プロジェクトに関するすべてのシステム関連ドキュメントをDocusaurusを使用してMarkdownで管理します。

クライアントへの提出が必要な場合は、MarkdownをエクスポートしてGoogle Docsなどを使用して提出します。
