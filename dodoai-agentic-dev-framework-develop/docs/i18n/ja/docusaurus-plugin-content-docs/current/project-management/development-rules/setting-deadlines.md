## 期限設定

## 概要

イシューの作成時にすべてのイシューに期限を設定することは、プロジェクト管理の実践であり、すべてのタスクやイシューに開始時から特定の完了時間を持たせます。これにより、プロジェクト管理と監視の能力が向上し、タスクが時間通りに完了し、見落とされることがありません。

## 目標

イシューの作成時に期限を設定する目的は、タイムリーな完了を保証し、プロジェクト管理と監視の能力を向上させ、タスクが見落とされるのを防ぎ、チームメンバー間での個人の責任感を促進することです。期限設定はまた、効果的なタスクの優先順位付けを助け、リソース利用を最大限に活用することにも寄与します。さらに、タスクが正しい順序で管理されないときに起こりうる競合を回避するのに役立ちます。

## なぜ期限を設定する必要があるのか？

1. **タイムリーな完了の保証**: タスクに対する具体的なタイムラインを提供し、進捗状況の追跡と監視を容易にします。
2. **見落とされたタスクの防止**: タスクが忘れられたり無視されたりしないようにします。
3. **責任感の創出**: チームメンバーに明確な期待と責任を設定します。
4. **優先順位付けを助ける**: 重要なタスクを特定し優先順位を付けることで、リソースの最適な使用を支援します。
5. **競合の回避**: タスクが正しい順序で管理されないときに起こる問題を防ぎ、スムーズなプロジェクトの実行を確保します。

## 誰がこのタスクを実行する責任を持つのか？

1. **プロジェクトマネージャー**: すべてのタスクに期限が設けられ、進捗が監視されていることを確認します。
2. **チームリーダー**: チームのタスクの期限設定と監督においてプロジェクトマネージャーをサポートします。
3. **チームメンバー**: 設定された期限に従い、タスクを時間通りに完了することを確保します。

### 要約すると、マネージャーができない場合には誰でもプロジェクトで自分のために期限（締め切り）を設定できます。これにより、作業効率が向上し、タスクに対する自己規律と責任感が促進されます。
