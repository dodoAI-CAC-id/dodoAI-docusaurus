## 概要

プロジェクトチャーターページのセットアップは、重要なプロジェクト情報を整理し、文書化する上で重要なステップです。このセットアップは情報の中心的なソースとなり、プロジェクトに関わるすべての関係者が簡単にアクセスし、コミュニケーションできるようにします。

適切に構造化されたプロジェクトチャーターページは、責任を明確に定義し、プロジェクトの進捗をシームレスに追跡し、プロジェクトライフサイクルの包括的な概要を提供します。

サンプルのプロジェクトチャーターページのセットアップについては、こちらをご覧ください: [サンプルプロジェクトチャーターページ](https://www.notion.so/Teamspace-Home-72edbd69dac14fb7ac039a6a4384fdb2?pvs=4)

## 基本情報

- Notion のホームページを構成し、プロジェクトの目的と目標を簡潔にまとめる。
- 役割と責任、プロジェクトのタイムライン、設計ドキュメントに関する包括的なセクションを含める。
- GitHub リポジトリや Google Drive などの外部リソースへのリンクを保持し、リソースを拡充する。
- 適切なアクセス権限を共有することで、ページがチームメンバーや関係者全員にアクセス可能であることを確認する。

## プロジェクトチャーターページのセットアップ方法

### **ステップ 1: Notion ホームページの作成**

- プロジェクト専用の新しいスペースを Notion で作成します。プロジェクトの関連情報（名前や説明）を設定し、プロジェクトの権限（プライベートを推奨）を選択します。

  <!-- ![Notion スペース作成](assets/project-charter-page-setup/create-notion-space.png) -->

- 「Create teamspace」をクリックしてプロジェクトページを作成。
- メンバーを即座に追加するには、検索ボックスに名前またはメールアドレスを入力するか、リンクをコピーしてメンバーに送信します。初期設定としてチームスペースだけを設定したい場合は、「Skip for now」を選択し、その後の設定に進みます。

- このスペースをプロジェクトチャーターのメインページとして指定し、プロジェクトの目標と重要なデータを反映させます。

### **ステップ 2: 必要なセクションの入力**

- **役割と責任:**
  - プロジェクトに関与する各チームメンバーの役割を明確に定義します。

  <!-- ![役割の定義](assets/project-charter-page-setup/role-definition.png) -->

- このステップは、[役割と責任](../project-management/role-and-responsibility.md)で説明した通りに完了し、ページに追加されていることを確認してください。

- **設計ドキュメント:**
  - Miro からのワイヤーフレームや Figma からの最終設計を埋め込むかリンクして、視覚的に確認できるようにします。

  <!-- ![設計アセット](assets/project-charter-page-setup/miro-and-figma.png) -->

- **GitHub リポジトリ:**
  - プロジェクトの GitHub リポジトリへのリンクを統合して、ソースコードを追跡できるようにします。

  <!-- ![GitHub 統合](assets/project-charter-page-setup/github-link.png) -->

- **その他の必要な情報:**
  - 開発者やプロジェクトに必要な情報の他に、スケジュール、会議メモ、プロジェクト概要、WBS（作業分解構成）、技術情報（テクノロジー）など、関連する詳細を追加できます。

### **ステップ 3: プロジェクトドキュメントのリンク**

- 標準の開発プロセスに従ってプロジェクトドキュメントを統合し、全体のワークフローとの整合性を確保します。

  <!-- ![ドキュメントリンク](assets/project-charter-page-setup/documentation-link.png) -->

- より詳細なプロジェクトの洞察を得るために、建設および設計ドキュメントを追加します。

  <!-- ![仕様設計ドキュメント](assets/project-charter-page-setup/spec-design-docs.png) -->

### **ステップ 4: 共有と協力**

- 完成した Notion ページをすべてのチームメンバーと関係者と共有し、コラボレーションを促進し、プロジェクト活動に完全に参加できるようにします。

  <!-- ![Notion ページを共有](assets/project-charter-page-setup/share-notion-page.png) -->

### **ステップ 5: メンテナンスと更新**

- プロジェクトの範囲、設計、チーム構成に変更があった場合、Notion ページを定期的に更新して、すべての関係者が最新の情報を把握できるようにします。
