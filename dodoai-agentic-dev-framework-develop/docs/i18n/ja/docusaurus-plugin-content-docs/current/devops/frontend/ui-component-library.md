## UI コンポーネントライブラリ

## 概要
UI コンポーネントライブラリは、複数のプロジェクトで共有できる再利用可能な UI 要素のコレクションです。これにより、デザインプロセスを効率化し、一貫したユーザー体験を提供できます。

## 目的
- UI コンポーネントの集中管理を行う。
- 異なるアプリケーション間で UI の一貫性を向上させる。
- デザインと開発のプロセスを迅速化する。

## 重要なポイント
- **既存の UI コンポーネントライブラリがプロジェクト内にある場合は、それを再利用して一貫性と効率性を維持する**。
- 再利用可能で柔軟に適用できるコンポーネントを設計する。
- 各コンポーネントの適切なドキュメントを用意する。
- 開発ツールとシームレスに統合できるようにする。

## サンプルコード
**注: 以下の例はフォーマットの参考用です。自身の UI コンポーネントライブラリに適用してください。**

### Web 用 Storybook
Storybook は、UI コンポーネントのインタラクティブな開発環境です。開発者はコンポーネントライブラリをブラウズし、異なる状態を確認しながら、コンポーネントの開発とテストを行えます。
![storybook.](../../../assets/storybook.png)

Storybook のセットアップと使用方法:
1. プロジェクトに Storybook をインストールする。
2. 各コンポーネントのストーリーを作成する。
3. Storybook を実行し、コンポーネントを確認・テストする。

```bash
// Storybook をインストール
npx sb init

// Storybook を起動
npm run storybook
```

### モバイル向け Widgetbook
Widgetbook は、Flutter ウィジェットを整理し、レスポンシブにテストできるツールです。開発者とデザイナーが効率的にコラボレーションできるようにサポートします。
![widgetbook.](../../../assets/widgetbook.png)

#### Widgetbook の統合方法
1. `pubspec.yaml` に `widgetbook` を依存関係として追加する。
2. 各ウィジェットとそのプロパティを定義する。
3. Widgetbook を実行し、異なる画面サイズやプラットフォームでウィジェットをテストする。

```yaml
dependencies:
  widgetbook: latest_version
```

これらのフレームワークを活用することで、UI コンポーネントライブラリを効率的に構築・管理し、開発ワークフローの改善と UI の一貫性向上を実現できます。
