# Engineer Request Process for the Project

Based on the technical and functional requirements of the project, ADF, and Roles and Responsibilities of the project, the PM should create an engineer request using the information outlined in the template below.

The request information should then be sent to Mr. Tri (@Tri (Le Cao Tri)) and cc: Mr. Murakami (@Jin/Hitoshi Murakami) via the tech-lead channel.

[Tech-lead Channel on Slack](https://58-crew.slack.com/archives/C050P7YTAUU)

## Engineer Request Template

### 1. Project Information

- **Project Name**: [Enter project name]
- **Project Description**: [Brief description of the project]

### 2. Position Details

- **Type**: [Frontend Engineer, Backend Engineer, Fullstack]
- **Programming Languages**: [Flutter, React, Python, Java, NodeJs...]
- **Additional Skills**: [knowledge of Blockchain, Firebase...]

### 3. Timeframe and Participation

- **Start Date**: [when work is to begin]
- **Duration**: [Duration needed: 2 weeks, 1 month...]
- **Participation Percentage**: [Percentage of time commitment, 25%, 50%, full-time]

### 4. Summary of the Tasks (Goals)

- Summary of the tasks (Goals) that the engineer will perform in the project.
