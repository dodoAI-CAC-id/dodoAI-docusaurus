# Update Github Project

Once an issue is registered, the Project Manager (PM) should update the GitHub project accordingly. This page provides guidelines for updating GitHub projects, including setting Iteration, Story Point, Start Date, and Due Date.

## Steps to Update the GitHub Project

1. **Iteration**
   - Assign the issue to the relevant iteration. This will help in tracking the progress of the issue over specific time periods.
   - Iteration equals a sprint and is set to a 1-week duration, i.e., 1 Week = 1 Iteration.

2. **Story Point**
   - Estimate the effort required to complete the issue by assigning story points. Story points help in understanding the complexity and effort involved in resolving the issue.
   - Story points indicate the size of the task. Use multiples of 2, such as 1, 2, 4, 8, and 16.
   - If the story point is 32 or more, it indicates that the task is too large. Ensure to split it into smaller tasks. (**Note:** This point is emphasized.)

3. **Start Date**
   - Set the start date for the issue. This is the date when the work on the issue is expected to begin.

4. **Due Date**
   - Set the due date for the issue. Ensure that the due date does not exceed the milestone completion date. The due date marks the deadline for resolving the issue.
   - *Note:* The due date should be set within the milestone's completion date to ensure timely delivery.

## Example

Here's an example of how to update these fields:

- Iteration: Sprint 5
- Story Point: 3
- Start Date: 2023-09-01
- Due Date: 2023-09-07

By following these guidelines, you can ensure that all issues are tracked and managed efficiently, leading to smoother project management and timely delivery.

## Key Points

- Iteration: Assign to relevant iteration for tracking.
- Story Point: Estimate effort required.
- Start Date: Expected start date of the issue.
- Due Date: Deadline for resolving the issue; ensure it does not exceed the milestone completion date.

This approach ensures that the project stays on track and all team members are aware of their responsibilities and deadlines.
