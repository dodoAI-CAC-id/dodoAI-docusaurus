# Setting Deadlines

## Overview

Setting deadlines for all issues upon creation is a project management practice that ensures every task or issue has a specific completion time from the start. This enhances project management and monitoring capabilities, ensuring that tasks are completed on time and not overlooked.

## Goals

The objective of setting deadlines for all issues upon creation is to ensure timely completion, enhance project management and oversight capabilities, prevent tasks from being overlooked, and foster individual accountability among team members. Setting deadlines also aids in effective task prioritization and maximizes resource utilization. Finally, it helps avoid conflicts when tasks are not managed in the correct order.

## Why Do We Need to Set Deadlines?

1. **Ensures Timely Completion**: Provides specific timelines for tasks, making it easier to track and monitor progress.
2. **Prevents Overlooked Tasks**: Ensures no tasks are forgotten or neglected.
3. **Creates Accountability**: Establishes clear expectations and responsibilities for team members.
4. **Aids Prioritization**: Helps identify and prioritize important tasks, optimizing resource use.
5. **Avoids Conflicts**: Prevents issues when tasks are not managed in the correct order, ensuring smooth project execution.

## Who is Responsible for Carrying Out This Task?

1. **Project Manager**: Ensures that every task has a deadline and monitors progress.
2. **Team Leads**: Assist the project manager in setting and overseeing deadlines for their team's tasks.
3. **Team Members**: Follow the established deadlines and ensure tasks are completed on time.

### In summary, anyone can set deadlines (due dates) for themselves in a project when the manager is unable to do so. This enhances work efficiency and fosters self-discipline and responsibility towards the tasks.
