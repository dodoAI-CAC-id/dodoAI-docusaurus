## Overview

Before starting with the GitHub Project Setup, it's essential to ensure that you have completed the setup for both GitHub and Notion. These preliminary steps are crucial for a smooth integration and workflow.

- [Github Setup](../project-management/github-setup.md)

Once the initial setup for GitHub and Notion is in place, you can move on to configuring your GitHub project. The goal is to create an intuitive and user-friendly environment for managing project progress. It offers robust support for developers, making it simpler to update the status of their work. With an efficiently designed interface, a myriad of management options opens up for users, enhancing the project management experience. The integrated tools in GitHub make tracking project roadmaps and progression hassle-free, propelling teams to streamline their development process and reach their goals with increased efficiency.

## Essential Information

- Configure the project's privacy settings.
- Link the GitHub project to the relevant repository.
- Remember, a repository can house multiple GitHub projects, each with its unique purpose.

## How to Set Up a GitHub Project

### Step 1: Initialize Your Project

- Begin by navigating to the "Projects" section on the repository and clicking on "New Project."

### Step 2: Configure Project Settings

- Continue by tailoring your project's structure:
  - You may start with either a standard template or one provided by your organization.
  
  - If you are using an organizational template, name your project appropriately and then select "Create Project." If you are using GitHub’s default templates, follow a similar naming process.

※ Note: You can change your project's name at any time, as exemplified below.

### Step 3: Manage Issues and Development Flow

- To organize issues and delegate tasks, link each issue directly to the project.

- Once linked, the issues will be visible in the project's dashboard, simplifying the tracking and management process.

### Step 4: Marking Milestones

- Proceed with the creation of GitHub Milestones to maintain a clear timeline for your project. Refer to this guide for the detailed process: [GitHub Milestone](../project-management/github-milestone-setup.md)
