## Overview

After completing your GitHub registration, please set up your GitHub project. Include a Gantt chart to give developers a clear outlook, present iterations (Scrum units), and organize tasks into milestones for efficient management. Also, set up iterations and a tab for managing developers' story points as per the iterations.

## Purpose

- To measure productivity for each project.
- To monitor Dev Velocity on a weekly basis.

## Steps to Install Iteration and Set Up a Story Point Management Tab

### Step 1: Access the Project

- Use this link to access the project: https://github.com/orgs/58web3/projects/{project_number}
- Alternatively, refer to the instructions in the image below:

### Step 2: Iteration Installation

- Click the "..." button in the top right corner and select "Settings."
- If an "Iteration" field is missing in "Settings," add it as follows:

1. Click "New Field" to open a pop-up.
2. In "Field Name," type "Iteration" and select "Iteration" for "Field Type."
3. Click "Save" to add the Iteration field to the settings.

- If "Iteration" exists or is added, click "Add Iteration" to introduce a new Iteration.

### Step 3: Sum Story Point Tabview Setup

1. Return to the project screen and select "+ New View," then choose tabview to create a new tabview.
2. Name the tabview "Sum Story Points."
3. Use the Advanced filters to fill in details as shown in the image.
